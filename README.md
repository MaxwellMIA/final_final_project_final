To run the game just open final_game.py and hit the play button on the top right of your screen.

For all commands, please type the word/s how you see them, spaces need to be included.

GAME - 
Get Scarlet a gift before her birthday in 4 days.
Complete daily tasks to get yourself into shape to see her.
There are five endings, how ever there is three different ways to get one of them.
1/5 is the worst ending as 5/5 is the best.
